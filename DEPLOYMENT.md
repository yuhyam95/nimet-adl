# Deployment Guide

This guide provides step-by-step instructions for deploying the NiMet Automated Data Loader on an Ubuntu/Debian production system.

## System Prerequisites
- **OS**: Ubuntu 22.04 LTS (Recommended) or similar Linux distribution
- **Node.js**: v18 or v20
- **PostgreSQL**: v14 or later
- **Process Manager**: PM2
- **Web Server**: Nginx

## 1. Database Setup

First, install PostgreSQL and create the required database and user.

```bash
sudo apt update
sudo apt install postgresql postgresql-contrib -y
```

Access the PostgreSQL prompt:
```bash
sudo -u postgres psql
```

Run the following SQL commands to set up the database (update the password as needed, making sure it matches your `.env` configuration):
```sql
CREATE DATABASE nimet_adl;
CREATE USER nimet_user WITH ENCRYPTED PASSWORD 'password';
GRANT ALL PRIVILEGES ON DATABASE nimet_adl TO nimet_user;
\c nimet_adl
GRANT ALL ON SCHEMA public TO nimet_user;
\q
```

## 2. Backend Setup

Clone your repository to the chosen directory (e.g., `/opt/nimet-adl`).

```bash
cd /opt  # or your preferred deployment directory
sudo git clone <your-repo-url> nimet-adl
sudo chown -R $USER:$USER nimet-adl
cd nimet-adl
```

Install backend dependencies:
```bash
npm install
```

Configure environment variables:
```bash
# Edit the .env file with your actual database credentials and API keys
nano .env
```
*(Make sure `DB_USER`, `DB_PASSWORD`, `DB_DATABASE`, and `DB_HOST` match the PostgreSQL credentials you created).*

Initialize the database schemas and required default data (like the Admin user):
```bash
node src/db/apply_init.js
node src/db/migrate_mappings.js
node src/db/seed_admin.js
```

Install PM2 globally and start the backend service:
```bash
sudo npm install -g pm2
pm2 start src/server.js --name "nimet-adl-backend"
pm2 save
pm2 startup
```
*(Run the command generated by `pm2 startup` to ensure PM2 restarts on system boot).*

## 3. Frontend Setup

The frontend is a React application built with Vite. It needs to be built into static files for production.

Install dependencies and build the static files:
```bash
cd frontend
npm install
npm run build
```

This will generate a `dist` folder at `frontend/dist` containing the production-ready HTML, CSS, and JS.

## 4. Nginx Configuration

We use Nginx to serve the compiled frontend React app efficiently and act as a reverse proxy to route `/api` requests to our Express backend.

Install Nginx:
```bash
sudo apt install nginx -y
```

Create a new Nginx configuration file for the application:
```bash
sudo nano /etc/nginx/sites-available/nimet-adl
```

Add the following configuration (replace `your_domain_or_IP` and the paths with your actual details):

```nginx
server {
    listen 80;
    server_name your_domain_or_IP;

    # Serve Frontend Static Files
    location / {
        root /opt/nimet-adl/frontend/dist;
        index index.html;
        # For React Router to work correctly on direct page hits
        try_files $uri $uri/ /index.html;
    }

    # Proxy API Requests to Backend
    location /api/ {
        proxy_pass http://localhost:3000/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

Enable the site and restart Nginx:
```bash
sudo ln -s /etc/nginx/sites-available/nimet-adl /etc/nginx/sites-enabled/
# Test Nginx config
sudo nginx -t
sudo systemctl restart nginx
```

## 5. Maintenance and Logging

To view backend application logs:
```bash
pm2 logs nimet-adl-backend
```

To restart the application after pulling new code:
```bash
cd /opt/nimet-adl
git pull origin main

# Backend updates
npm install
pm2 restart nimet-adl-backend

# Frontend updates
cd frontend
npm install
npm run build
```
